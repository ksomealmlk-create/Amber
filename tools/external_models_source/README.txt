External model source pack included with Amber.

Pack: Stylized Nature MegaKit - FREE Standard version (68 of 116 models)
Creator: Quaternius
License: CC0 1.0 Universal
Official page: https://quaternius.com/packs/stylizednaturemegakit

The original glTF files and their dependent textures/buffers are kept here for future editing.
The Flutter game currently uses pre-rendered transparent PNG sprites derived from selected models.
Runtime sprites are in assets/world_models/ and are loaded by Sprites.load().
The original glTF source files in this folder are not bundled into the APK.
