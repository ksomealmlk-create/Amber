# الجمرة التائهة 3D — نموذج 2.5D (المرحلة 1)

لعب جانبي بمحرك Godot 4.3 (Mobile renderer): مجسمات ثلاثية الأبعاد، إضاءة وظلال، توهج (Bloom)، ضباب، بارالاكس حقيقي، جسيمات، وبطل راكون بأنميشن مفاصل.
منطق اللعب (الفيزياء والأعداء والفخاخ وبيانات المرحلة) منقول حرفياً من نسخة Flutter.

## البناء (APK)
1. ارفع محتويات هذا المجلد لمستودع GitHub جديد (أو Amber مع مجلد فرعي).
2. Actions ← "Build Amber3D APK" ← Run workflow.
3. نزّل `Amber3D-apk` من Artifacts. الحزمة: com.amber.game3d (تتعايش مع نسخة Flutter).

## التحكم
لمس: أسهم يمين/يسار، ▲ قفز، ⚔ ضرب، ≫ اندفاع. كيبورد: A/D أو أسهم، Space قفز، J ضرب، K اندفاع.

## الملفات
- scripts/sim.gd: المحاكاة (60 خطوة/ث) · level_data.gd: المرحلة (مولّدة من Dart)
- world.gd: البيئة والتضاريس · view.gd: الأعداء والفخاخ والكنوز · hero.gd: البطل · fx.gd: المؤثرات · hud.gd: الواجهة واللمس
- tools/export_level.py: يحوّل أي مرحلة من world1.dart إلى level_data.gd

لم تُنقل بعد: الزعيم، النوابض، المفاتيح، الفقاعات، المراحل 2–10 (المحاكاة جاهزة للتوسعة).
